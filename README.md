# Natural Twenty

A single-file HTML d20 that tumbles on a felt tray with real rigid-body physics, bounces off the rim, and rolls with synthesized dice sounds. Built with Claude as a vibe coding demo.

- Tap the table, press Space, or use the Roll button.
- No build step and no dependencies to install. Three.js loads from a CDN.

To publish: Settings > Pages > deploy from the `main` branch, root folder.
